# SAISTA COFFEE

Premium coffee journey prototype built with Next.js, TypeScript, React Three Fiber and Three.js.

## Run locally

```bash
npm install
cp .env.example .env.local
npm run dev
```

`NEXT_PUBLIC_WHATSAPP_NUMBER` controls every WhatsApp CTA. The included number is a demo placeholder and must be replaced before launch.

## Content safety

This repository intentionally labels origin, farm, process, imagery, founder story and testimonials as demo content. Replace them through `lib/content.ts` and the related visual assets after verification by SAISTA COFFEE.
